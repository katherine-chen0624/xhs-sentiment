# 小红书雪球股票舆情监测 Skill

每日自动抓取小红书和雪球的股票相关讨论，以专业金融分析师视角输出 HTML 舆情日报。

---

## 核心逻辑

| 数据源 | 定位 | 用途 |
|--------|------|------|
| 🔴 小红书 | 散户反向风向标 | 讨论越热、情绪越亢奋 → 风险越高 |
| 🟡 雪球 | 专业投资者中性参考 | 热股榜 + 讨论量反映市场关注度 |

两源结合，既能捕捉散户非理性情绪，也能参考相对理性的专业讨论。

---

## 功能

- **综合风险指数**：基于小红书散户情绪，0-100 评分
- **雪球热股榜**：当日热度最高的 9 只个股及涨跌幅
- **热点标的自动发现**：从双源数据中识别今日冒头的个股/板块
- **Watchlist 专项追踪**：用户自定义个股/板块，每日深度分析情绪分布、套牢压力
- **前日复盘**：对照昨日判断与实际收盘价，追踪判断准确性
- **多日趋势推断**：连续信号识别，主动推送过热预警或底部信号
- **HTML 日报输出**：每日生成可视化报告，浏览器直接打开

---

## 安装

1. 将 `xhs-xueqiu-sentiment.skill` 文件放入 Claude Skills 目录：
   ```
   /mnt/skills/user/
   ```
2. 确保 **Claude in Chrome** 扩展已安装并连接
3. 在浏览器中**登录小红书和雪球**（保持登录态即可）

---

## 使用方法

### 触发日报

在 Claude 对话中直接说：

```
今日舆情
跑一次舆情
出日报
刷新日报
小红书舆情
雪球舆情
```

### 管理 Watchlist

```
把比亚迪加入 watchlist
监测光模块板块
每日跟踪宁德时代和半导体ETF
从 watchlist 移除 XX
```

### 前日复盘

每天收盘后告诉 Claude 收盘价：

```
今天上证指数收盘 4026，恒生科技ETF 收盘 6.85
```

Skill 会自动对照昨日判断，计算准确率并更新校准权重。

---

## 首次使用

第一次运行时，Skill 会询问你想监测哪些个股或板块。

- **有自选标的**：告知名称，自动加入 Watchlist
- **暂无自选**：默认运行**宏观大盘模式**，覆盖大盘情绪 + 雪球热股 + 热点发现

    ├── keywords.md             # 每日必搜关键词（分级）

## 输出示例

每日生成 `daily_report_YYYYMMDD.html`，包含：

- 🌡️ 综合风险仪表盘（0-100）
- 📰 前日复盘对照表
- 🔥 小红书大盘情绪 TOP5（最新排序）
- 📈 雪球热股榜 Top9
- 🆕 今日热点标的（双源融合）
- 📌 Watchlist 专项卡片（情绪分布条形图 + 套牢压力）
- 🧠 多日趋势推断
- 🔔 智能预警（有信号时自动显示）

---

## 注意事项

- 小红书抓取使用**最新排序**，反映当日真实新帖，非历史高赞帖
- 所有分析仅供参考，**不构成投资建议**
- 小红书散户情绪为**反向指标**，热度高 ≠ 买入信号
- 建议积累 7 日以上数据后，复盘准确率才有参考价值
