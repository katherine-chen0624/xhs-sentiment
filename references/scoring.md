# 风险评分规则

## 评分框架

每条帖子的风险得分 = 基础分 × 热度系数 × 情绪系数 × 账号系数

最终**今日综合风险指数** = Σ(所有帖子得分) / 总帖子数，归一化到 0-100

---

## 基础分：关键词命中级别

| 命中关键词级别 | 基础分 |
|--------------|--------|
| 一级关键词 | 30 |
| 二级关键词 | 20 |
| 三级关键词 | 10 |
| 未分级（标题语义相关）| 5 |

---

## 热度系数：点赞数

| 点赞数 | 系数 |
|--------|------|
| ≥ 500 | × 3.0 |
| 200 - 499 | × 2.0 |
| 50 - 199 | × 1.5 |
| 10 - 49 | × 1.2 |
| < 10 | × 1.0 |

> 注：点赞数为空（刚发布）时默认系数 × 1.0

---

## 情绪系数：标题情绪词检测

在帖子**标题**中检测以下情绪词，命中则乘对应系数：

### 亢奋追涨词（风险放大）
| 情绪词 | 系数 |
|--------|------|
| 快冲 / 快买 / 快上车 | × 2.0 |
| 梭哈 / 满仓 / all in | × 2.0 |
| 暴涨 / 大涨 / 一飞冲天 | × 1.8 |
| 必买 / 强推 / 闭眼买 | × 1.8 |
| 抄底 / 低点 / 底部 | × 1.5 |
| 赚了 / 赚翻了 / 赚麻了 | × 1.5 |
| 救命 / 哇 / 绝了 | × 1.3 |
| 姐妹 / 集美 / 家人们 | × 1.3 |

### 恐慌出逃词（潜在底部，风险降低）
| 情绪词 | 系数 |
|--------|------|
| 割肉 / 止损 / 清仓 | × 0.7 |
| 亏了 / 亏死了 / 亏麻了 | × 0.8 |
| 套牢 / 被套 / 解套 | × 0.8 |
| 后悔 / 踩坑 / 避雷 | × 0.7 |
| 不玩了 / 退出 / 放弃 | × 0.6 |

### 中性分析词（不调整）
| 情绪词 | 系数 |
|--------|------|
| 复盘 / 分析 / 研究 | × 1.0 |
| 推荐 / 测评 / 对比 | × 1.0 |
| 攻略 / 教程 / 入门 | × 1.0 |

> 规则：一条帖子只取**最高情绪系数**，不叠加

## 账号系数：账号类型判断

| 账号特征 | 系数 | 说明 |
|---------|------|------|
| 素人账号（无蓝V、粉丝推算<1万）| × 1.5 | 真实散户，信号最强 |
| 普通用户（无特殊标记）| × 1.2 | 默认分类 |
| 认证账号/蓝V | × 0.8 | 可能是机构/品牌，信号弱化 |
| 疑似营销号（名字含"股票导师""分析师"）| × 0.5 | 过滤营销噪音 |

> 实操：当前版本通过作者名简单判断，如名字含"老师"、"导师"、"分析"等词则降权

## 综合风险指数计算

```python
# 伪代码示例
def calculate_risk_index(posts):
    scores = []
    for post in posts:
        base = get_keyword_tier_score(post.keyword)
        heat = get_heat_coefficient(post.likes)
        emotion = get_emotion_coefficient(post.title)
        account = get_account_coefficient(post.author)
        score = base * heat * emotion * account
        scores.append(score)
    
    raw_index = sum(scores) / len(scores) if scores else 0
    # 归一化到 0-100（假设理论最大值为 90）
    normalized = min(100, (raw_index / 90) * 100)
    return round(normalized, 1)
```

## 风险等级解读

| 综合风险指数 | 等级 | 市场含义 | 历史规律 |
|------------|------|---------|---------|
| 0 - 30 | 🟢 低风险 | 散户关注度低，情绪平稳 | 市场可能处于底部或震荡期 |
| 31 - 60 | 🟡 中风险 | 散户参与度上升，开始活跃 | 行情上升中段，尚未过热 |
| 61 - 80 | 🟠 高风险 | 散户情绪亢奋，大量新人入场 | 历史上多为中短期顶部信号 |
| 81 - 100 | 🔴 极高风险 | 全民炒股，情绪极度亢奋 | 强烈反向信号，历史顶部特征 |

## 特殊信号识别

### 强烈顶部信号（任一出现即单独预警）
- 同一天内一级关键词帖子数 > 20 条
- 单条帖子点赞数 > 1000（散户情绪帖）
- "瞒着家人买"类帖子当日出现 > 3 条
- 7日环比讨论量增长 > 150%

### 潜在底部信号（供参考，不作主要依据）
- 恐慌出逃词帖子占比 > 60%
- "亏了/割肉"类帖子点赞数居高（散户共鸣高）
- 连续5日综合风险指数 < 20

## 归因质量评级

对搜索到的新闻进行质量评级，只采纳 A/B 级信源：

| 级别 | 信源 | 说明 |
|------|------|------|
| A | 巨潮资讯（公告）、上交所/深交所公告 | 一手官方信息 |
| A | 财联社、彭博中文、路透中文 | 专业财经媒体 |
| B | 东方财富、同花顺、雪球精选 | 主流财经平台 |
| C | 微信公众号、百度百家号 | 参考，不作主因 |
| D | 小红书内容本身、抖音 | 仅作舆情来源，不作归因 |
